# rust-practice-chatper-wise-for-beginners

Hello fellow Rustlings, I am currently learning Rust using the Rust book. The book
does not offer many exercises chapter wise, nor could I find any source, article or
asset that would give me problems to practise chapter wise. So I thought of going
chapter by chapter and doing exercises myself, and then I realised maybe I could
share it for other learners.

The solutions I have written may not be the best solutions out there, but this is
just for learning, so please do not mind them.

A chapter-wise Rust practice repository for beginners, where each chapter folder
holds small hands-on exercises so you can follow along, build muscle memory, and
learn by writing real code instead of just reading.

## Chapters are based on

[The Rust Programming Language (The Book)](https://doc.rust-lang.org/book/)

## How to use this repo

- Work through the book chapter.
- Then open the matching `chapter_N/` folder and try the exercises there.
- Each exercise lives in its own Cargo project, so you can run each one
  independently:

```bash
cd chapter_3/temp_converter
cargo run
```
